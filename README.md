# Iron Rig (working title)

A turn-based artillery tank game for the browser. Set your angle and power, read the wind, and fire across hills that blow apart. 2 to 4 tanks, each human or computer (Easy, Normal, Hard). Pass the device for local play.

**This is a test build (Stage 1).** It's not finished. Money, a weapon store (napalm and more) and more personality come in later stages.

- Stage 1: https://jweiland1978.github.io/tank-game/stage1/index.html?v=1

Works offline after loading, with no ads, tracking or outside requests. Sounds are generated in the browser.

## Made with AI

Designed with AI help and built with Grok Build (an AI coding agent). Code, art (drawn in code) and sounds (synthesized in code) were made with AI.
